## 💼 MyPortfolio

## 📝 概要
このプロジェクトは、転職活動を目的として制作したWebサイト  
設計・デザイン・コーディングまでを担当

## 🔧 使用技術
- HTML5 / CSS3 
- Illustrator/ Photoshop / Figma（デザイン制作）

## 💡 工夫した点
- 写真に触れるとhoverとカーソルが付与
- どの画面幅でもレイアウトが崩れないようレスポンシブ対応  
- alt属性・title属性を適切に設定し、アクセシビリティを意識  
- 色を使いすぎず、ユーザーに見やすい作品を意識

## 📱 対応デバイス
- PC / Tablet / Smartphone（レスポンシブ対応）

## 🖼️ デザイン
- デザインカンプ: Figma  
- 各作品に合う色のトーンやフォントを意識
